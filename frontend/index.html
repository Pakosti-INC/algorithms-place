Восстановление мозаики

Ограничение времени
2 с
Память

В университетской мастерской восстанавливают мозаику. Она представляет собой прямоугольное поле из n × m клеток. Некоторые клетки заполнены, остальные пусты.

Определите количество отдельных фрагментов мозаики. Две заполненные клетки принадлежат одному фрагменту, если между ними можно пройти по заполненным клеткам через общую сторону.

Формат ввода

В первой строке даны n и m (1 ≤ n, m ≤ 1000). Следующие n строк содержат по m символов: «#» обозначает заполненную клетку, «.» — пустую.

Формат вывода

Выведите одно целое число — количество отдельных фрагментов мозаики.

Ввод:
3 4
Вывод:
2
